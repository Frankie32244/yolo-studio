# ONNX Runtime Web assets

The `.mjs` and `.wasm` files in this directory are the matching 1.22.0 WebAssembly runtime from the official `onnxruntime-web` npm package.
They are hosted with the site so no external CDN is required.

Copyright Microsoft Corporation. MIT License: https://github.com/microsoft/onnxruntime/blob/v1.22.0/LICENSE

Update these files together with `onnxruntime-web` when changing its version.
